============================================================================================
How each operation constructs its return value (sunpy/timeseries/timeseriesbase.py)
============================================================================================
  add_column      self.__class__(data, meta, units)
  remove_column   self.__class__(data, deepcopy(meta), units)
  truncate        self.__class__(data.sort_index(), meta, copy(units))
  concatenate     self.__class__(...) if all operands share a class,
                  else GenericTimeSeries(...)   [NOT switched on same_source]
  sort_index      GenericTimeSeries(...)   <- hardcoded, downcasts
  extract         GenericTimeSeries(...)   <- hardcoded, downcasts

Every one of these calls the three-argument constructor positionally.
There is no _new_instance / _replace hook a subclass can override, so a
subclass carrying extra state loses it even when its type is preserved.
